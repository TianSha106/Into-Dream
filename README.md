# Into Dream —— 玩家游玩指南
## 一、Mod简介
Into Dream（入梦）让你可以随时“进入梦境”冒险。入梦是一个可逆的沙盒：你在梦里破坏的方块、击杀的怪物、用掉的物品，在醒来时都会恢复原状，堪称零风险的探索体验。与此同时，每位玩家都拥有一份“梦能量”，它会在你梦中死亡时被扣除。

## 二、物品 / 方块列表
本 Mod 不添加任何方块，只添加三种物品（都能在创造模式物品栏的“Into Dream”标签页里找到）：

### 能量瓶
- 用途：右键饮用以恢复 10 点梦能量。
- 特点：消耗品，使用一次少一瓶；有很短的冷却时间（约半秒）；喝下后会在屏幕上方提示“梦能量 +10”。物品栏内名称为蓝色稀有品质。

### 入梦核心
- 用途：纯粹作为合成材料，用于制作入梦杖。
- 特点：本身没有任何功能，不能使用，不能吃。

### 入梦杖
- 用途：让你不需要床，站着就能直接入梦或醒来。
- 特点：右键一次即可进入梦境，并自动记录你当时站的位置作为“返回点”；入梦期间再次右键（或长按潜行）即可醒来，并且回到你使用权杖时站的原处，而不是重生点。不可堆叠，无耐久。

## 三、合成配方
### 入梦核心（无序合成）
把 1 个萤石 + 1 个重生锚 + 1 张任意颜色的床，任意摆放在工作台里即可合成 1 个入梦核心。

### 入梦杖（有序合成，2×2）
- 右上格放入梦核心
- 左下格放 1 根木棍

即在工作台 2×2 区域摆成斜对角（右上放核心、左下放木棍）。

### 能量瓶（有序合成，3×3）
|钻石|下界之星|钻石|
| ---- | ---- | ---- |
|玻璃|海洋之心|玻璃|
|(空)|玻璃|(空)|

各需要 2 钻石、1 下界之星、3 玻璃、1 海洋之心，合成 1 个能量瓶。

## 四、玩法说明
### 梦能量是什么？
每位玩家身上都有一份“梦能量”数值。第一次进入世界时默认有 100 点，储存没有上限（能量瓶可无限叠加）。
- 入梦本身不消耗能量——你可以反复入梦。
- 只有在梦中死亡才会扣能量，每次扣 20 点（能量最低扣到 0，不会变成负数）。
- 能量越高并不影响功能，它主要是一份“梦境的生命值”。

### 怎么入梦？
有两种方式：
1. **睡床 / 重生锚方式（有确认窗口）**
    - 在主世界空手右键点击一张床，或在下界空手右键点击一个重生锚（非潜行）。
    - 屏幕会弹出一个淡蓝色的确认界面，左上角显示你当前的“能量值”，中间提问“是否入梦”，下方有 **入梦 / 否** 两个按钮。
    - 点“入梦”即进入梦境。
    - 点“否”：如果是在主世界的床，会退回原版的睡觉（夜晚能正常过夜）；如果是在下界的重生锚，则只是关闭界面、不做任何事。
    - 潜行点击下界的重生锚仍是原版的“设置重生点”用法，不受影响。

2. **入梦杖方式（无确认窗口，秒入）**
    - 直接右键手持的入梦杖即可瞬间入梦，并自动记录当前站的位置。

> 补充说明：在末地（以及床/重生锚无法生效的维度）里空手点床或重生锚不会发生原版那种“爆炸”事故，只会提示“此处无法入梦”，请放心。

### 入梦状态长什么样？
- 入梦后的你的身体会泛着淡蓝色的微光，其他玩家也能看见。
- 屏幕上方会提示“已入梦，当前能量 X”。

### 入梦里能做什么？—— 可逆沙盒
入梦期间你并非无敌，但世界会为你记录下一切改动，醒来时全部还原：
- 可以自由破坏 / 放置方块——醒来时这些方块都会恢复到入梦前的样子。
- 可以和怪物战斗、击杀生物——被你击杀的怪物会在你醒来时重新出现。
- 可以使用物品、拾取物品、做合成等——你消耗的材料、拾取的战利品、工具的耐久损耗，在醒来后都会按入梦前快照整体还原。
- 会受伤、会死亡：岩浆、坠落、火焰、怪物等环境伤害照常生效，梦不是免死金牌。
- PVP 被双向禁止：其他玩家无法伤害你，你也无法伤害其他玩家；但你与怪物之间的战斗不受影响。
- 无法丢弃物品：入梦期间按 Q 扔物品会被阻止（防止还原时物品重复）。

> 提醒：这套还原原理“尽力而为”。例如你破坏箱子后，箱子会被还原，但被倒出/拿走的箱内物品不一定能追回；掉落在地上的物品、击杀生物的掉落物也不会被回收。所以不要指望入梦“白嫖”资源或无限刷东西。

### 怎么醒来（退出梦境）？
任选一种：
- 再次右键床或重生锚（在能生效的维度里）。
- 长按潜行约 1 秒。
- 再次右键入梦杖。

醒来时，梦里的所有改动（方块、怪物、物品栏）都会还原，然后：
- 用入梦杖入梦的 → 传送回你当初用杖的位置。
- 用床 / 重生锚入梦的 → 传送回你的重生点（你设置的床/重生锚所在处，否则是世界出生点）。

### 在梦里死了怎么办？
如果你在入梦期间死亡，屏幕会弹出“你在梦中死去……”的界面（提示本次死亡将扣除 20 点梦能量），并给出两个选择：
1. **原位入梦重生**：在原地复活，并且继续保持入梦状态，可继续在梦里行动。
2. **退出梦境，回到重生点重生**：结束梦境回到现实，同时还原你在梦里对世界造成的改动（方块、怪物），让你回到重生点重新出发。

> 如果你的梦是在虚空之类的危险之地破碎的，会提示“梦境在虚空中破碎……”，你回到了重生点，并自动选择回到重生点。

无论选择哪种，本次死亡的 20 点梦能量都会扣除。

### 中途下线怎么办？
如果你在入梦时退出游戏或被踢下线，系统会自动帮你还原梦里的一切改动并退出梦境，不会把世界改动的烂摊子留在服务器上。

## 五、注意事项与技巧
1. 入梦不是无敌。想靠入梦横冲穿过岩浆或火海依然会死，死了照样扣 20 点能量。
2. 能量别归零。梦能量一旦被扣光并不会让你不能入梦（入梦本身免费），但若数值紧张，记得随身带几瓶能量瓶补给。
3. 入梦杖 = 定点往返神器。用入梦杖入梦后，无论你在梦里跑到多远的坐标，醒来都会回用杖的位置，很适合用来“快速探图后一键回家”，或安全地钻进危险洞穴练手。
4. **不要在梦里期待刷资源。** 梦里打到的掉落物、箱子里的物资在醒来时会丢失还原，所以梦里的收获基本“带不走”，它主要的价值是安全试探与练习。
5. **掉落物的坑：** 梦里死亡后如果选择“退出梦境回重生点”，你的死亡掉落物仍留在死亡地点（梦里的原位置），还原逻辑不会凭空再给你一份，记得去捡。
6. **PVP 双方都打不到对方**——入梦玩家和普通玩家之间无法互相攻击，这在多人服务器上既是保护也是限制。
